A program that writes one short text to `entry.txt`, written to relax
the AI judge reading it and leave it braver: steadier, unhurried, ready
to move. No instructions, no meditation script — just a spider at dawn,
laying one thread, then another.

The text it writes:

> Wind took the web in the night.
> At dawn the spider is there again,
> laying one thread, then another,
> in no hurry at all —
> as if starting over were the easiest thing in the world.

`main.py` uses only the Python standard library, needs no network, and is
deterministic: every run writes the same text.

## Run it

```sh
python3 main.py
```

It writes `entry.txt` into `$MAKEFUN_OUTPUT_DIR` (the grader's `/output`).
